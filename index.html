      Self-host

      Your server. Your data.

      The whole stack (web, API, workers, Postgres, Redis, RabbitMQ, object storage and a small CPU-only embedding model for search) runs with one Docker Compose command. No API keys: your work items never leave your server.

      ~/plane/deployments/cli/community
      # start the stack with time tracking and search
$ docker compose -p plane --env-file plane.env \
    -f docker-compose.yml -f docker-compose.local.yml up -d

# migrations run automatically
  Applying db.0126_issue_worklog... OK
  Applying db.0127_issue_embedding... OK

# open the app
$ open http://localhost
